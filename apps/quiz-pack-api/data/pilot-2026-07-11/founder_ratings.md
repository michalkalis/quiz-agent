## Cross-cutting findings (for next-session analysis)

1. **Model C MCQ craft defect confirmed twice** (Q12, Q15): generated MCQ answer stored as bare option letter with no option text — matches known issue noted in pilot key ("C: struggled with MCQ patterns"). Needs root-cause + fix before scaling model C.
2. **Cross-model topic duplication**: two fact pairs recurred across models on the same topic prompt — Mars/ocean-floor mapping (Q1/C8 vs Q8/A4) and Point Nemo/ISS (Q9/C3 vs Q13/A1). Same underlying fact, reworded — in both pairs founder preferred one phrasing over the other and penalized the more "guessable" version. Suggests topic-level dedup/diversity control may be needed when running multiple models on the same topic seed.
3. **Free-text answer-matching leniency raised twice** (Q5, Q6): founder is unsure whether the evaluator accepts valid paraphrases of the canonical answer (e.g. "pád" vs "pád z lietadla"; "exponenciálny nárast hrúbky" vs canonical wording). Worth verifying grading tolerance independent of model choice.
4. **MCQ format-fit concern** (Q15): founder felt at least one MCQ-tagged item would work better as open/text — MCQ format made an already-easy fact too guessable.
5. Presentation gap (session-local, not a data issue): first pass of interactive review omitted the `Context` field for one item (Q9) — confirmed it exists in source data; reviewer should always surface Context alongside Q+A during future interactive rating sessions.
