   - The tunnel: `fly proxy 15432:5432 -a quiz-pack-db` (keep it running).
   - Run claude inside the gui-domain tmux (Keychain).
2. Generate. Six arms, three to six in parallel:
   - `GATEWAY=session ./run_arm.sh E en H_en` and `F en M_en`
   - `S sk H_sk` and `T sk M_sk`
   - `C cs H_cs` and `D cs M_cs`
   - Each arm runs 37 themes × 2 questions. The pilots ran six arms in parallel without hitting a limit.
   - A subscription-limit error stops the arm (`QUOTA` in `run.log`). Rerun the same command after the window resets; finished themes are skipped.
3. Duplicate review:
   - `python3 run_dups.py . ../general-pilot-2026-10-14 ../topics-pilot-2026-10-14 > list.txt` lists all ~310 questions (new plus pilots).
   - A Sonnet subagent names the same-fact pairs. Pairing rule: same language, or en vs sk/cs; never sk vs cs.
   - Drop rule: keep the en row and drop the sk/cs copy; within a language, drop the later one.
   - Write the drops into `drops.txt`, one id per line exactly as `run_dups.py` prints it.
   - Also drop pilot questions the founder rated ≤ 5 (`ratings_raw/` + `blind_key.json` in each pilot dir).
4. Gate:
   - `python3 build_sample.py drops.txt` builds 20 per language from the new questions only.
   - Publish `rating.html` as an artifact with `capabilities: {db: {}}`.
   - The founder rates. Read the ratings with ArtifactData `list ratings`.
   - Import only at an average ≥ 7 per language. If below, stop and ask.
5. Import:
   - Merge all survivors (new plus pilot questions, variety-pilot excluded) into `merged-{en,sk,cs}.json`.
   - Copy `docs/testing/runs/native-sk-cs-2026-10-08/run_import.sh` with the paths changed. Run `--dry-run` first, then `--execute`.
