## Agent Brief — 2026-08-14

**Category:** enhancement
**Summary:** One idempotent backfill importer per source into the #154 canonical store, plus verification that the #154 export then covers every historical round — the input for D21 calibration and the P1 frozen eval set.

**Current behavior:** No script merges any of these; the only consumer of any rating field is the gold-library loader (`load_gold_standard`, ≥8 filter).

**Desired behavior:**
- A backfill CLI in quiz-pack-api with one parser per source, writing ratings rows with `source = backfill:<round>`, original raw score + scale bounds, rated-at date (round date where per-row dates don't exist), rater = founder (gold library rows keep `rated_by`, importing only human ones — `auto` rows excluded), and per-source identity resolution: UUID where recoverable (mapping.json joins, order/text join for the baseline with a fail-loud report of unjoinable rows), otherwise question-text snapshot as identity. Provenance extras (arm, model, topic, prompt version) go into the JSON extras field.
- **Idempotent:** re-running produces zero duplicates (natural key per source, e.g. source + original id/text + rater).
- **Fail loud:** every source prints imported/skipped/unjoinable counts; the July-calibration round is registered as a documented note (in the issue close-out + a marker row or README, no fake data).
- In-app prod `ratings.db`: check the prod Fly volume once; if empty (expected — plumbing had no UI), record that and close the source; if not, import via the same CLI.
- Close-out: run the #154 export and record total consolidated count per round in this issue; flag the D19 follow-up (critique re-anchoring, candidate 13) as unblocked — do **not** touch prompts here.

**Key interfaces / call paths:**
- #154 ratings table + export script (the contract this fills).
- Source files above; `mapping.json` join logic; `founder_ratings.md` / `corpus-blind-sample` MD table parsing.
- `data/examples/gold_standard.json` is read-only input — the gold library itself is NOT rewritten here (refresh is a later candidate-11 use, after D21).

**Acceptance:** see the top-level `## Acceptance` block.

**Out of scope:**
- Any prompt/model/threshold change; gold/anti library refresh; critique re-anchoring (candidate 13).
- Building the frozen eval set itself (P1 comes after D21 ratings exist) — this delivers its data substrate.
- New rating collection (that's #154/#155).

pytest on the parsers (fixture snippets per source format, idempotency test = run importer twice, assert count unchanged); then a real local run against a dev DB and a manual spot-check of 3 rows per source against the source files.
